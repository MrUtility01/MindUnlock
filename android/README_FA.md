# MindUnlock Android — مسیر ساخت 0.5.1

نسخهٔ اندروید Native با Kotlin و Jetpack Compose است. ورودی اصلی ساخت CI فایل آرشیوی `MindUnlock-Android-v0.3.1-source.zip` در ریشهٔ مخزن است؛ پوشهٔ `android/` شامل مستندات و تنظیمات پایه است و منبعی که Workflow استخراج می‌کند همان آرشیو است.

## قابلیت‌ها و تغییرات هدف نسخهٔ 0.5.1

- نگهداری محتوای آموزشی و داده‌های کاربر در پایگاه‌های جداگانه، با هدف حفظ پیشرفت قبلی هنگام ارتقا.
- بارگذاری مرحله‌ای محتوای فصل‌ها و کنترل همگام‌سازی.
- انتخاب مدل گفتار فارسی و دریافت مدل‌ها هنگام نیاز، به‌جای قراردادن همهٔ مدل‌ها در APK.
- مسیرهای مطالعه، مرور، فلش‌کارت، آزمون و آزمایشگاه.
- دریافت و نگهداری محتوای آفلاین پس از همگام‌سازی.

## ساخت و کنترل کیفیت

Workflow گیت‌هاب مراحل `testDebugUnitTest` و `assembleDebug` را اجرا می‌کند؛ سپس صحت ZIP، وجود APK و شناسهٔ بسته را بررسی می‌کند. این کنترل‌ها جایگزین آزمون نصب و اجرای واقعی روی دستگاه Android، آزمون مهاجرت از داده‌های نسخهٔ نصب‌شده و بررسی دستی تمام مسیرهای رابط کاربری نیستند. نتیجهٔ هر اجرا را در GitHub Actions بررسی کنید.

APK این Workflow از نوع **debug** است و برای انتشار عمومی باید نسخهٔ release با امضای امن و کلید مدیریت‌شده خارج از مخزن ساخته شود.

## معماری ارتباط و امنیت

ارتباط با برنامهٔ ویندوز در این نسخه بر پایهٔ HTTP شبکهٔ محلی است. آن را به اینترنت عمومی یا پورت فورواردشده متصل نکنید؛ برای استفادهٔ خارج از LAN باید TLS، احراز هویت و کنترل دسترسی سمت سرور پیاده‌سازی و آزموده شود.

## نصب

پس از موفقیت Workflow، فایل APK را از بخش Artifacts همان اجرای GitHub Actions دریافت و روی دستگاه سازگار نصب کنید. محدودیت ABI و حداقل نسخهٔ Android را از خروجی Build و مشخصات Manifest همان APK بررسی کنید؛ از روی این مستندات حدس نزنید.
