# MindUnlock اندروید — نسخه پایه

اپلیکیشن Native (Kotlin + Jetpack Compose) برای مطالعه آفلاین محتوای برنامه ویندوز.

## چه چیزی پیاده‌سازی شده؟

| قابلیت | وضعیت |
|--------|--------|
| اتصال به سرور ویندوز با IP و پورت | ✅ |
| دریافت Manifest فصل‌ها | ✅ |
| دانلود فصل + آیتم‌ها و ذخیره Room | ✅ |
| رد شدن از فصل‌هایی که content_hash یکسان دارند | ✅ |
| لیست فصل‌های ذخیره‌شده | ✅ |
| صفحه مطالعه محتوا (درس، نکته، سؤال، آزمون، آزمایشگاه و...) | ✅ |
| کار کاملاً آفلاین پس از همگام‌سازی | ✅ |
| تولید محتوا / پرامپت / ساخت موضوع | ❌ عمداً حذف شده |

## نصب سریع

1. Android Studio را باز کنید.
2. پوشه `android` را Open کنید.
3. روی Run کلیک کنید (یا `./gradlew assembleDebug`).
4. APK را روی گوشی (Android 8 به بالا، تست‌شده برای Android 15) نصب کنید.

## اتصال به ویندوز

- برنامه ویندوز را اجرا کنید.
- IP لپ‌تاپ/کامپیوتر را از تنظیمات شبکه یا با دستور `ipconfig` پیدا کنید.
- در اپ، همان IP و پورت ۸۲ را وارد و همگام‌سازی کنید.
- گوشی و کامپیوتر باید روی یک وای‌فای باشند.

## نکات امنیتی

ارتباط فقط HTTP روی شبکه محلی (LAN) است. پورت را هرگز به اینترنت عمومی باز نکنید.
